# Project Handsfree

USSD typed for you. Your PIN stays yours.

- `:core:model` — pure Kotlin/JVM data models
- `:core:engine` — pure Kotlin/JVM flow engine (depends on `:core:model`)
- `:app` — Android Compose app (depends on `:core:engine`)
